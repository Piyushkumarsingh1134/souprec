# Souprec

Souprec is a browser-based audio and video recording platform inspired by Riverside.fm. It is designed to help creators, teams, and hosts record high-quality conversations directly from their browser while providing a simple and reliable user experience.

## Live Demo

https://souprec-4w92vfy4i-piyushkumarsingh1134-3916s-projects.vercel.app/

## About the Project

I built Souprec to learn and implement real-time communication technologies used in modern video conferencing and podcast recording platforms. The project focuses on creating a seamless experience for users to join rooms, communicate, and record conversations in real time.

## Features

- Create and join recording rooms
- Real-time audio and video communication
- Browser-based recording experience
- Responsive and modern user interface
- Secure room-based collaboration
- Optimized for desktop and mobile devices
